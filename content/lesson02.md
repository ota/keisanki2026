## 前回のおさらい {#review}

- 変数は `型 変数名 = 値;` の形で作ります。
- `printf` で値を表示するときは、型に合った書式指定子を使います。
  - 整数は `%d`、小数は `%f`、文字は `%c`、文字列は `%s` です。
- `\n` は改行です。`\` は、キーボードの `¥` のキーで入力します。

次のコードは、前回の内容を使っています。
コードを読んで、何が表示されるか予想してから実行しましょう。

:::exercise warmup review.c given
```c
#include <stdio.h>

int main(void) {
    int number = 99;
    float pi = 3.14;

    printf("%d\n", number);
    printf("%f\n", pi);
    return 0;
}
```
:::

:::expected warmup
```
99
3.140000
```
:::

:::concepts
- `%f` は小数点以下を6桁表示するので、`3.14` は `3.140000` と表示されます。
  - 桁数を決める方法は、この後の「算術演算子」で学びます。
- 分からないところは、[第1回の「変数」](./lesson01.html#variable)で確かめます。
:::

## 算術演算子 {#arithmetic}

`+`、`-`、`*`、`/`、`%` は計算に使う記号で、「算術演算子」と呼びます。
掛け算は `×` ではなく `*`、割り算は `÷` ではなく `/` と書きます。

- 記号は次のキーで入力します。
  - `+` はShiftと `;`、`*` はShiftと `:` のキーです。
  - `/` は `.` の右隣のキー、`%` はShiftと `5` です。

:::exercise arithmetic calc.c
```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 3;

    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    return 0;
}
```
:::

:::expected
```
a + b = 13
a - b = 7
a * b = 30
```
:::

:::concepts
- `printf` の `%d` の位置に、`a + b` などの計算結果が入ります。
- 二重引用符の中の `a + b = ` は文字列なので、計算されずにそのまま表示されます。
:::

次は割り算です。整数同士の割り算には、注意する点があります。

:::exercise division divide.c
```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 3;

    printf("a / b = %d\n", a / b);
    printf("a %% b = %d\n", a % b);
    return 0;
}
```
:::

:::expected
```
a / b = 3
a % b = 1
```
:::

:::concepts
- `int` 同士の `/` は、小数部分を切り捨てた整数になります。`10 / 3` は `3` です。
  - Pythonでは `10 / 3` は `3.333…` でした。Cの整数同士では `3` になります。
  - Javaの授業でも同じです。
- `%` は割り算の余りです。`10 % 3` は `1` です。
- `printf` で `%` という文字を表示するには、`%%` と2つ並べます。
  - `%d` などの書式指定子と区別するためです。
:::

:::check division
**下の欄にコピーして、`a` を `17`、`b` を `5` に変えます。
割り算の答えと余りを予想してから実行しましょう。**
:::

小数同士の割り算では、答えも小数になります。

:::exercise float-division float_divide.c
```c
#include <stdio.h>

int main(void) {
    float x = 10.0;
    float y = 3.0;

    printf("x / y = %f\n", x / y);
    printf("x / y = %.2f\n", x / y);
    return 0;
}
```
:::

:::expected
```
x / y = 3.333333
x / y = 3.33
```
:::

:::concepts
- `float` 同士の `/` は、小数の答えになります。
- `%f` は、小数点以下を6桁表示します。
  - `%.2f` と書くと、小数点以下2桁まで表示します。3桁目は四捨五入されます。
:::

:::check float-division
**下の欄にコピーして、`%.2f` を `%.4f` に変えて実行しましょう。**
:::

## キャスト演算子 {#cast}

値の前に `(float)` のように型を書くと、その型に変換できます。
これを「キャスト」と呼びます。

:::exercise cast cast.c
```c
#include <stdio.h>

int main(void) {
    int a = 7;
    int b = 2;

    printf("整数のまま：%d\n", a / b);
    printf("キャスト：%f\n", (float)a / b);
    printf("2桁まで：%.2f\n", (float)a / b);
    return 0;
}
```
:::

:::expected
```
整数のまま：3
キャスト：3.500000
2桁まで：3.50
```
:::

:::concepts
- `(float)a` は、`a` の値を小数の `7.0` に変換します。
  - 割る数か割られる数の片方が小数なら、もう片方も自動で小数に変換されます。
  - そのため、`(float)a / b` は小数の割り算になり、`3.5` です。
- 書式指定子は、計算結果の型に合わせます。
  - 小数の結果は `%f`、整数の結果は `%d` で表示します。
:::

:::check cast
**下の欄にコピーして、2行目の `(float)a / b` を `(float)(a / b)` に変えて実行しましょう。
表示がどう変わるか確かめます。**
括弧の中が先に整数で計算されて `3` になり、そのあとで小数に変換されます。
:::

文字と、その文字を表す番号（文字コード）も変換できます。

:::exercise char-code char_code.c
```c
#include <stdio.h>

int main(void) {
    char letter = 'A';
    int code = 66;

    printf("%c = %d\n", letter, (int)letter);
    printf("%d = %c\n", code, (char)code);
    return 0;
}
```
:::

:::expected
```
A = 65
66 = B
```
:::

:::concepts
- コンピュータの中では、文字は番号で表されています。この番号を「文字コード」と呼びます。
  - 英数字の文字コードは「ASCII（アスキー）コード」で決まっています。
- `(int)letter` は文字を文字コードに、`(char)code` は文字コードを文字に変換します。
:::

| 文字 | `'0'` | `'1'` | `'A'` | `'B'` | `'a'` | `'b'` |
| --- | --- | --- | --- | --- | --- | --- |
| 文字コード | 48 | 49 | 65 | 66 | 97 | 98 |

- アルファベットの文字コードは、`A`・`B`・`C`… の順に1ずつ増えます。
  - 小文字も同じく、`a` から順に1ずつ増えます。

:::check char-code
**下の欄にコピーして、`'A'` を `'a'` に、`66` を `67` に変えて実行しましょう。**
:::

## 代入演算子とインクリメント {#assign}

`=` は、右側の値を左側の変数に入れる「代入」です。
`+=` を使うと、今の値に足してから代入できます。

:::exercise compound compound.c
```c
#include <stdio.h>

int main(void) {
    int score = 80;
    printf("はじめ：%d\n", score);

    score += 10;
    printf("10点追加：%d\n", score);

    score *= 2;
    printf("2倍：%d\n", score);
    return 0;
}
```
:::

:::expected
```
はじめ：80
10点追加：90
2倍：180
```
:::

:::concepts
- `score += 10;` は `score = score + 10;` と同じ意味です。
  - 数学の「左右が等しい」という意味ではありません。
- `-=`、`*=`、`/=`、`%=` も同じように使えます。
  - `score *= 2;` は `score = score * 2;` と同じ意味です。
- この書き方は、Javaの授業でも同じです。
:::

:::check compound
**下の欄にコピーして、`score *= 2;` を `score -= 30;` に変えます。
表示の文字も「30点減点」に直してから実行しましょう。**
:::

1だけ増やす・減らすときは、`++` と `--` を使うと短く書けます。

:::exercise increment increment.c
```c
#include <stdio.h>

int main(void) {
    int count = 0;
    printf("count = %d\n", count);

    count++;
    printf("count = %d\n", count);

    count--;
    printf("count = %d\n", count);
    return 0;
}
```
:::

:::expected
```
count = 0
count = 1
count = 0
```
:::

:::concepts
- `count++;` は1増やします。これを「インクリメント」と呼びます。
  - `count = count + 1;` や `count += 1;` と同じ意味です。
- `count--;` は1減らします。これを「デクリメント」と呼びます。
- Pythonでは `++` と `--` は使えません。CとJavaでは使えます。
  - 第4回の「繰り返し」でよく使います。
:::

`++` は変数の前にも後ろにも書けます。
`printf` の中で使うと、表示される値が変わります。

:::exercise prefix prefix.c
```c
#include <stdio.h>

int main(void) {
    int a = 0;

    printf("a = %d\n", ++a);
    printf("a = %d\n", a++);
    printf("a = %d\n", a);
    return 0;
}
```
:::

:::expected
```
a = 1
a = 1
a = 2
```
:::

:::concepts
- `++a`（前置）は、先に1増やしてから、その値を使います。
- `a++`（後置）は、今の値を使ってから、1増やします。
  - 2行目は `1` を表示した後で増えるので、3行目で `2` になります。
- 違いが分かりにくいので、迷ったら `a++;` のように1行で使います。
:::

## 比較演算子と論理演算子 {#compare}

2つの値を比べる記号を「比較演算子」と呼びます。
比べた結果は、成り立つなら `1`、成り立たないなら `0` になります。

| 演算子 | 意味 | 例（`a` が10、`b` が5） |
| --- | --- | --- |
| `==` | 等しい | `a == b` は `0` |
| `!=` | 等しくない | `a != b` は `1` |
| `>` | より大きい | `a > b` は `1` |
| `<` | より小さい | `a < b` は `0` |
| `>=` | 以上 | `a >= b` は `1` |
| `<=` | 以下 | `a <= b` は `0` |

- 等しいかを比べるときは `==` と2つ並べます。
  - `=` を1つだけ書くと「代入」になり、比較になりません。
- `<` `>` はShiftと `,` `.` のキー、`!` はShiftと `1` です。

:::exercise compare compare.c
```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 5;

    printf("a == b : %d\n", a == b);
    printf("a != b : %d\n", a != b);
    printf("a > b : %d\n", a > b);
    printf("a < b : %d\n", a < b);
    return 0;
}
```
:::

:::expected
```
a == b : 0
a != b : 1
a > b : 1
a < b : 0
```
:::

:::concepts
- `1` は「成り立つ（真、true）」、`0` は「成り立たない（偽、false）」を表します。
- 比較演算子は、次回の「条件分岐」で使います。
:::

:::check compare
**下の欄にコピーして、`b` を `10` に変えます。
4つの結果がどう変わるか、予想してから実行しましょう。**
:::

複数の条件を組み合わせるときは、「論理演算子」を使います。

| 演算子 | 意味 | 結果が `1` になるとき |
| --- | --- | --- |
| `&&` | かつ（AND） | 両方とも成り立つとき |
| `\|\|` | または（OR） | どちらか片方でも成り立つとき |
| `!` | ではない（NOT） | 条件が成り立たないとき |

- `&` はShiftと `6`、`|` はShiftと `¥` のキーです。

:::exercise logic logic.c
```c
#include <stdio.h>

int main(void) {
    int score = 75;

    printf("%d\n", score >= 60 && score <= 100);
    printf("%d\n", score < 30 || score > 90);
    printf("%d\n", !(score >= 60));
    return 0;
}
```
:::

:::expected
```
1
0
0
```
:::

:::concepts
- 1行目は「60以上、かつ100以下」です。`75` は両方を満たすので `1` です。
- 2行目は「30未満、または90より大きい」です。どちらも満たさないので `0` です。
- 3行目の `!` は結果を反対にします。`score >= 60` は `1` なので、`0` になります。
- 数学のように `60 <= score <= 100` とは書けません。
  - `&&` で2つの比較に分けて書きます。
:::

:::check logic
**下の欄にコピーして、`score` を `95` に変えます。
3つの結果を予想してから実行しましょう。**
:::

## 演算子の優先順位 {#order}

数学と同じく、演算子には計算する順番（優先順位）があります。

| 順番 | 演算子 |
| --- | --- |
| 1 | `( )` 括弧 |
| 2 | `!`、`++`、`--`、キャスト `(float)` など |
| 3 | `*`、`/`、`%` |
| 4 | `+`、`-` |
| 5 | `<`、`<=`、`>`、`>=` |
| 6 | `==`、`!=` |
| 7 | `&&` |
| 8 | `\|\|` |
| 9 | `=`、`+=` などの代入 |

:::exercise order order.c
```c
#include <stdio.h>

int main(void) {
    printf("%d\n", 1 + 2 * 3);
    printf("%d\n", (1 + 2) * 3);
    printf("%d\n", 10 + 5 > 12 && 3 * 2 == 6);
    return 0;
}
```
:::

:::expected
```
7
9
1
```
:::

:::concepts
- 1行目は、先に `2 * 3` を計算します。
- 2行目は、括弧の中の `1 + 2` を先に計算します。
- 3行目は、算術、比較、論理の順に計算します。
  - `10 + 5` は `15`、`3 * 2` は `6` です。
  - `15 > 12` は `1`、`6 == 6` も `1` です。
  - 最後に `1 && 1` で `1` になります。
- 順番に迷ったら、括弧で囲むと確実です。
:::

### 発展3　エラーを直す

誤りがあると、実行結果の欄にエラーが表示されます。

:::expected
main.c:5:13: error: expected expression
:::

- `main.c:5:13` は「5行目の、左から13文字目あたり」という意味です。
  - `error:` の後に、エラーの内容が英語で表示されます。上の例は「式が必要」です。
- 誤りのある場所は、表示された行の少し前のこともあります。前後の行も見ます。

次のコードには、それぞれ誤りがあります。
まず実行してエラーを確かめ、直してから再実行しましょう。

:::exercise fix-compound score.c fix
```c
#include <stdio.h>

int main(void) {
    int score = 80;
    score + = 10;
    printf("%d\n", score);
    return 0;
}
```
:::

次のコードはエラーなく動きますが、`a == b` の結果が `0` ではなく `5` と表示されます。
正しく `0` と表示されるように直しましょう。

:::expected fix-equal
a == b : 0
:::

:::exercise fix-equal equal.c fix
```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 5;

    printf("a == b : %d\n", a = b);
    return 0;
}
```
:::

次のコードは、`score` が「60以上100以下か」を調べるつもりです。
`120` は範囲の外なので、`0` と表示されるように直しましょう。

:::expected fix-range
0
:::

:::exercise fix-range range.c fix
```c
#include <stdio.h>

int main(void) {
    int score = 120;

    printf("%d\n", 60 <= score <= 100);
    return 0;
}
```
:::

次のコードは `7` と `8` の平均を求めますが、`7.500000` ではなく `7.000000` と表示されます。
`7.500000` と表示されるように直しましょう。

:::expected fix-average
平均：7.500000
:::

:::exercise fix-average average.c fix
```c
#include <stdio.h>

int main(void) {
    int a = 7;
    int b = 8;
    float average = (a + b) / 2;

    printf("平均：%f\n", average);
    return 0;
}
```
:::

:::hint
- 1つ目：`+=` の間に空白は入れられません。`score += 10;` と書きます。
- 2つ目：`a = b` は代入です。`b` の値 `5` が `a` に入り、その値が表示されます。
  - 比べるときは `a == b` と書きます。
- 3つ目：`chained comparison 'X <= Y <= Z' does not behave the same as a mathematical expression` は「比較をつなげた式は、数学の式と同じ意味にならない」。
  - `60 <= score` が先に計算されて `1` になり、次に `1 <= 100` が計算されるためです。
  - `score >= 60 && score <= 100` と2つに分けて書きます。
  - コンパイラによっては、エラーにならずに `1` と表示されることがあります。
- 4つ目：`(a + b) / 2` は整数同士の割り算なので、小数部分が切り捨てられます。
  - `(float)(a + b) / 2` のように、キャストで小数の割り算にします。
:::

## 今日のまとめ {#summary}

- `+`、`-`、`*`、`/`、`%` で計算する。`int` 同士の `/` は小数部分を切り捨てる。
- `(float)` などのキャストで型を変える。文字と文字コードも変換できる。
- `+=` などの代入演算子や、`++`・`--` で変数の値を変える。
- 比較演算子の結果は `1` か `0`。`&&`・`||`・`!` で条件を組み合わせる。
- 計算の順番に迷ったら、括弧で囲む。

次回は、比較演算子と論理演算子を使って「条件分岐」を学びます。
