# 計算機基礎演習 — Web教材試作

後期第1回「C言語プログラミング入門」のWeb教材です。本文は2026年度のシラバスの第1週に合わせ、構成と演習問題は昨年度の `R7_2I計算機基礎演習_第1回.pptx` を参考にしました。元のPowerPointファイルとローカル保存先を記した `slides.txt` は、このリポジトリには含めません。

「C言語とは」のロゴ画像（`public/images/c-language-logo.png`）は、同資料の7枚目から取り出しました。

## 起動

Node.js 20.19以降、または22.12以降が必要です。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。配布用ファイルは `npm run build` で `dist/` に生成できます。HTMLを直接開くのではなく、Webサーバで配信してください。

## 表示された教材を直接編集する

```sh
npm run edit
```

教員用の編集画面がブラウザで開きます。通常は `http://127.0.0.1:5173/__editor/lesson01` です。既に `npm run dev` を起動している場合は、そのサーバーのURLに `/__editor/lesson01` を付けて開けます。

1. 本文や箇条書きをクリックして、その場で編集します。
2. 箇条書きの項目は Enter で追加します。階層はツールバーの「字下げ」「字上げ」、または Tab / Shift+Tab で変更します。
3. 見本コードは「見本コードを編集」で開きます。教員用のコード欄では貼り付けもできます。
4. 「原稿を保存」（Ctrl+S / macOSでは⌘S）で `content/lesson01.md` に保存します。
5. 「学生表示」で、保存後の教材と演習の動作を確認します。

ツールバーでは太字、インラインコード、箇条書きへの変更、元に戻す・やり直すも操作できます。元に戻す操作は、現在編集中の文章・箇条書きの範囲に適用されます。

試作の編集対象は**本文・箇条書き・見本コード**です。ページのタイトル、章の見出し、表、画像、出力例、演習の追加や並べ替えは、引き続きZedなどでMarkdownを編集してください。変更した文章の範囲内ではMarkdownの表記が整えられる場合がありますが、未編集の箇所はそのまま保存します。

### 保存とZedとの併用

- 未保存の変更はブラウザ内に下書きとして保持し、同じブラウザ・同じURLで開き直すと復元します。ファイルへの保存は「原稿を保存」で行います。
- 保存前のMarkdownは `.local/author-backups/` に残します。このフォルダはGit管理対象外です。
- ZedでMarkdownを保存すると、編集画面も更新されます。ブラウザに未保存の編集がある場合は、自動で置き換えず、保存を止めて通知します。
  - 「編集中の原稿を書き出す」で手元の変更をMarkdownとして退避できます。
  - 「最新の原稿を読み込む」でZed側の変更を読み込み、退避した内容と見比べて必要な編集を戻します。
- 保存はこのPC内の原稿の更新です。GitHub Pagesへの公開は、確認後にGitへコミット・pushする別の操作です。

編集画面と保存APIはローカルの開発サーバーだけで動作し、このPCからのみ利用できます。`npm run build` の配布物には含まれません。ブラウザ内の下書きは、サイトデータの削除やプライベートブラウズの終了では失われるので、作業の区切りに原稿へ保存してください。

保存・競合防止・バックアップなどの確認は `npm test` で実行できます。

## Markdownで講義を編集する

第1回の本文は [`content/lesson01.md`](content/lesson01.md) にあります。`index.html` と `src/generated/lesson01-samples.js` は生成物なので直接編集せず、Markdownを変更してください。`npm run dev` では保存時に自動生成され、`npm run build` でもビルド前に生成されます。手動で生成する場合は `npm run generate` を実行します。

- `## 見出し {#id}` が本文の区切りと左側の目次になります。段落、箇条書き、リンク、表、インラインコードは通常のMarkdownで書けます。
- `:::exercise first hello.c` の中に `c` のコードフェンスを書くと、コピーできない見本画像、入力欄、実行ボタンを生成します。コードフェンスなしの `:::exercise task1` は自分で考える演習用です。IDはページ内で重複させないでください。
- `:::goals`、`:::howto`、`:::about-c`、`:::concepts`、`:::check`、`:::notice`、`:::expected`、`:::hint` は第1回で使っている表示用ブロックです。`:::notice` は注意書きを赤色で表示します。書き方は第1回のMarkdownを参照してください。
- 新しい回は `content/lesson02.md` のように追加します。第1回は `index.html`、以降は `lesson02.html` のように生成されます。新しいファイルを追加したときは開発サーバを再起動してください。

ページの共通部分は `templates/page.html`、見た目は `src/style.css`、実行と保存は `src/main.js` と `src/export.js` にあります。これらの変更は全回に反映されます。

## 実装

- 見本のCコードは Canvas に描画し、通常のテキスト選択やコピーをできなくしています。
- 入力欄は貼り付け・ドロップを拒否し、手入力したコードを各演習欄ごとに `localStorage` へ即時保存します。再読み込み後に復元され、画面に保存状態を表示します。
- `@live-codes/clang-wasm` の Clang を Web Worker 内で動かし、Cコードをブラウザ内でコンパイル・実行します。初回は約29 MBの実行資産を読み込みます。
- 長時間の実行は20秒で停止し、Workerを作り直します。
- ページ末尾で出席番号と氏名を入力すると、教材本文、入力済みコード、表示中の実行結果、保存情報を単一のHTMLファイルに書き出せます。見本とロゴは画像として、スタイルはHTML内に埋め込みます。

この制御は学習時の写経を促すためのものです。ブラウザの開発者ツール、OCR、スクリプトなどを使った取得まで防ぐことはできません。また Canvas の見本はスクリーンリーダーで読めないため、必要な学生には別形式の見本を提供する運用が必要です。

自動保存は同じ端末・同じブラウザ内に限られます。プライベートブラウズ、サイトデータの削除、端末の故障では復元できません。保存に失敗した場合は各入力欄の下に表示します。

書き出し時に入力する出席番号と氏名は `localStorage` に保存しません。保存情報には端末の時計による日時、ブラウザが公開するUser-Agent・プラットフォーム・言語・画面サイズを記録します。PCのログイン名や学校アカウントは取得できません。HTMLファイルと端末由来の情報は後から変更できるため、本人確認や改ざん防止の証拠にはなりません。

R7資料のMoodle登録キー、提出ファイル名、教員プロフィールは年度固有なので掲載していません。この試作は実行とHTML保存まで対応し、課題提出先との連携はしていません。
