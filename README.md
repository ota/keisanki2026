# 計算機基礎演習 — Web教材試作

後期第1回「C言語プログラミング入門」のWeb教材です。本文は2026年度のシラバスの第1週に合わせ、構成と演習問題は昨年度の `R7_2I計算機基礎演習_第1回.pptx` を参考にしました。元のPowerPointファイルとローカル保存先を記した `slides.txt` は、このリポジトリには含めません。

「C言語とは」のロゴ画像（`public/images/c-language-logo.png`）は、同資料の7枚目から取り出しました。

## 起動

Node.js 20.19以降、または22.12以降が必要です。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。配布用ファイルは `npm run build` で `dist/` に生成できます。HTMLを直接開くのではなく、Webサーバで配信してください。

## GitHub Pages

`main` ブランチへの push で GitHub Actions がビルドし、`https://ota.github.io/keisanki2026/` に公開します。リポジトリの Settings → Pages で Build and deployment の Source を **GitHub Actions** に設定してください。公開先のサブパスに合わせたビルドは `.github/workflows/deploy.yml` で指定しています。

## 実装

- 見本のCコードは Canvas に描画し、通常のテキスト選択やコピーをできなくしています。
- 入力欄は貼り付け・ドロップを拒否し、手入力したコードを各演習欄ごとに `localStorage` へ即時保存します。再読み込み後に復元され、画面に保存状態を表示します。
- `@live-codes/clang-wasm` の Clang を Web Worker 内で動かし、Cコードをブラウザ内でコンパイル・実行します。初回は約29 MBの実行資産を読み込みます。
- 長時間の実行は20秒で停止し、Workerを作り直します。

この制御は学習時の写経を促すためのものです。ブラウザの開発者ツール、OCR、スクリプトなどを使った取得まで防ぐことはできません。また Canvas の見本はスクリーンリーダーで読めないため、必要な学生には別形式の見本を提供する運用が必要です。

自動保存は同じ端末・同じブラウザ内に限られます。プライベートブラウズ、サイトデータの削除、端末の故障では復元できません。保存に失敗した場合は各入力欄の下に表示します。

R7資料のMoodle登録キー、提出ファイル名、教員プロフィールは年度固有なので掲載していません。この試作は実行まで対応し、課題提出先との連携はしていません。
